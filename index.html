Comprendre les concepts de Pivoting

Le Pivoting sert à créer des "ponts" pour attaquer des machines inaccessibles en rebondissant sur une machine compromise.

1. Proxy Dynamique (-D)

L'usage : Scanner tout le réseau caché.

Comment : Le tunnel transforme la machine compromise en proxy SOCKS. Tu utilises proxychains nmap ...

2. Redirection Locale (-L)

L'usage : Accéder à un service précis.

Comment : Prends le port interne, sors-le en local. Ouvre http://127.0.0.1:8080.

3. Redirection Distante (-R)

L'usage : Attraper un Reverse Shell isolé.

Comment : Expose ton port d'écoute sur la machine compromise pour que la cible s'y connecte.

Méthodologie d'une cyberattaque

Les phases de la « kill chain » offensive, expliquées pas à pas pour l'apprentissage.

Objectif pédagogique : comprendre comment un attaquant procède permet de mieux défendre un système. Chaque phase indique aussi comment la détecter et s'en protéger. N'applique ces techniques que sur tes propres systèmes ou des environnements d'entraînement autorisés (HackTheBox, TryHackMe, labs perso).
